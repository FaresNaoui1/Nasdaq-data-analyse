# NASDAQ Data Analysis

Exploratory data analysis and price prediction on NASDAQ stock data, implemented in a Jupyter notebook.

## 🚀 Overview

This project explores historical NASDAQ stock data to uncover trends and patterns, and builds a predictive model to forecast future price movements. It was built as a hands-on exercise in applying data science and machine learning techniques to real-world financial time-series data.

## 📊 What's Inside

- Data cleaning and preprocessing of NASDAQ stock price data
- Exploratory data analysis (EDA) and visualization of price trends
- Feature engineering for time-series forecasting
- Model training and evaluation for stock price prediction

## 📦 Tech Stack

- Python 3.x
- Pandas / NumPy
- Matplotlib / Seaborn
- scikit-learn
- Jupyter Notebook
